AWS

DevOps End-to-End Project

This project demonstrates an end-to-end CI/CD pipeline implementation using AWS, Jenkins, and Docker — from source code to a running container in production.

Deployment successful — built, pushed, and running on AWS EC2.

Technologies used

  • AWS EC2 (Ubuntu)
  • Jenkins (CI/CD automation)
  • Docker (containerization)
  • Docker Hub (image repository)

Project workflow

  1. Created EC2 instances for Jenkins and the application server
  2. Configured the Jenkins pipeline
  3. Built the Docker image
  4. Pushed the image to Docker Hub
  5. Deployed the container on the application server
